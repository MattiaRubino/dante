## Boundary

The retained package intentionally excludes unfinished or unnecessary mascot derivatives and exploratory material, including construction/model sheets, expression systems, pose systems, activity/runtime work and pixel-retro experiments.

The accepted symbol, wordmark, primary signature and mascot base must not be silently redesigned. Future derivative work requires a fresh bounded scope.
