## Locked identity

- clearly feline, stylized and non-photoreal;
- adult, angular/faceted proportions rather than chibi/kawaii proportions;
- dark charcoal/navy cosmic-watercolor body;
- warm orange/amber eyes, chest and forelegs/paws;
- restrained constellation / network-like surface language;
- one tail only;
- slender upward orbital tail ending in a small sun-like orange element with orbit language;
- secondary DANTE/LifeOS companion, not the primary logo.

## Rejected drift

Do not reinterpret the base character as realistic, fluffy, Pokémon/Eevee-like, Egyptian/sphinx-like, robotic, occult, or as a generic black cat with pasted-on logo marks.

## Production implication

The approved surface contains raster watercolor/cosmic texture. Production therefore uses a hybrid 2D master: the approved raster remains render authority while an SVG layer carries controlled construction geometry for downstream derivatives.
