## Cluster 1 — Intention / Execution

```text
Verification assessment
!= Goal identity
!= Plan identity
!= Activity/Event/Routine identity
!= Milestone identity
!= execution/completion/attainment by itself
```

Criterion/Evaluation may assess these targets where useful, but Verification does not manufacture intended or realized state.

## Cluster 2 — Time

```text
Verification != Schedule
Verification != Temporal Constraint
Verification != Recurrence
```

A temporal window may be part of a Criterion/evaluation context without becoming Verification identity.

## Cluster 3 — Observed Reality / Evidence

```text
Verification != Actual / Outcome / Observation
Verification != Evidence
Verification != Confirmation
Verification != Provenance
```

`verified-for-purpose != universal truth`. Missing Evidence may remain unknown/indeterminate; correction does not silently rewrite historical basis.

## Cluster 4 — Data / Subjects

Verifier is a contextual Actor role. Verification does not create Person, Actor, Account, Principal, Subject, Asset or Resource identity and does not grant Authority/Visibility.

## Relationships / Reasoning
