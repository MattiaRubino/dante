# 2026-08-16 — Asset relation integration

Ownership / Possession / Custody v0 completes a previously deferred boundary around Asset without changing the Cluster 4 identity model.

```text
Asset
= native individually tracked physical-object identity

Ownership / Possession
= specific contextual relations around that identity

Custody
= bounded entrusted/safeguarding profile
```

Therefore:

```text
new owner != new Asset
new possessor != new Asset
new custodian != new Asset
lost possession != loss of Asset identity
sale may change Ownership while Asset identity persists
```

Person, Actor, Account, Subject, Resource and Collective semantics remain unchanged. Ownership/Possession do not manufacture native identity, Actor capability, Subject aboutness or Resource eligibility.
