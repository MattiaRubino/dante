# 2026-08-16 — Contribution integration

Contribution v0 adds actor-scoped attribution around actual materially meaningful input/work without changing Goal, Plan, Activity, Event, Routine or Milestone identity.

```text
Activity intention != Contribution
requested/assigned work != Contribution
expected performer != Contributor automatically
Actual performer != complete Contribution attribution universally
```

The phrase that an Activity/Plan “contributes to” or supports a Goal remains planning/evaluative language and must not be confused with Actor Contribution.

```text
Activity supports Goal
→ planning / Criterion-Evaluation semantics

Actor materially contributed actual input/work
→ Contribution
```

No synthetic `Coordinate X`, `Contribute to X` or equivalent Activity is required merely to encode a relation that already has independent semantic meaning.

accepted identities unchanged
Contribution boundary integrated

UNCLASSIFIED 0
