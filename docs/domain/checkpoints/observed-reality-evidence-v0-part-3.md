# 2026-08-16 — Contribution integration

Contribution v0 is integrated without reopening the accepted Observed Reality primitive set.

```text
Actual
= contextual realization

Outcome
= contextual result/disposition

Provenance
= bounded lineage

Contribution
= actor-scoped relation around materially meaningful actual input/work
  in a bounded realization/result/output context
```

Therefore:

```text
Contribution != Actual
Contribution != Outcome
Contribution != Provenance
Contribution != Evidence
Contribution != Confirmation
```

Contribution is **not** a new Observed Reality primitive/root. It is a specific contextual relation whose assertions may be supported by Observation/Evidence/Provenance and whose correction/history follows the accepted non-destructive reality rules.

```text
no Evidence != proof of no Contribution
correction != silent overwrite
shared Actual/Outcome != duplicated per contributor
```
