# 2026-08-16 — Contribution versus Actual

Contribution v0 adds actor-scoped attribution around realized work without changing Actual identity.

```text
Actual
= contextual realization of an expectation/intention

Contribution
= materially meaningful actual input/work attributable to an Actor
  within a bounded realization/result/output context
```

Therefore:

```text
Actual != Contribution
shared Actual != per-Actor Contribution
Actual performer != complete Contribution attribution universally
```

A shared Actual may coexist with multiple distinct actor Contributions. LifeOS must not duplicate the shared realization once per contributor.

Actual performance can be evidence for or coincide with Contribution where context makes it materially meaningful, but performer identity is not a universal substitute for Contribution.

Correction remains non-destructive:

```text
later contribution-attribution correction
!= rewrite of the Actual itself
```

Where the Actual was recorded correctly but contributor attribution changes, the shared Actual remains stable and the actor-scoped attribution/history changes under its own semantics.
