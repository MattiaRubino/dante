# 2026-08-16 — Ownership integration

Ownership / Possession / Custody v0 confirms that a plurality of owners does not manufacture Collective identity.

```text
multiple owners != Collective automatically
Membership != Ownership
```

A true Collective may bear Ownership where the Collective referent is genuinely the owner:

```text
Collective C → Ownership → Asset A
```

but:

```text
Collective Ownership
!= every member personally owns A

member Ownership
!= Collective Ownership automatically
```

Likewise possession/custody by one member is not automatically possession/custody by the Collective, and vice versa.
