# 2026-08-16 — Collective / Membership integration

A true Collective may bear Coordination Stewardship where the ongoing coordination burden truthfully belongs to the Collective referent.

```text
Collective C
→ Coordination Stewardship for bounded context X
```

This does not collapse Collective identity into Stewardship and does not create Collective identity from multiple Stewards.

```text
Collective != Coordination Stewardship
Membership != Coordination Stewardship
member != Steward automatically
multiple Stewards != Collective automatically
```

Collective Stewardship may coexist with member-specific Responsibility, Participation, Authority or actual coordination actions without equivalence.
