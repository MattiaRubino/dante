# 2026-08-16 — Contribution integration

Contribution v0 resolves the previously deferred boundary between ongoing coordination burden and actual collaborative contribution.

```text
Coordination Stewardship
= who carries ongoing burden of keeping a bounded coordination context attended

Contribution
= materially meaningful actual input/work attributable to an Actor
  within a bounded realization/result/output context
```

Therefore:

```text
Coordination Stewardship != Contribution
Steward != Contributor automatically
Contributor != Steward automatically
actual coordination action != Stewardship state
actual coordination action may be Contribution only when materially meaningful in the bounded realized context
```

An Actor may carry Stewardship without materially contributing to a particular realized output. Another Actor may materially contribute without carrying the surrounding coordination burden.

Examples:

```text
Anna keeps the project attended, notices exceptions and follows up
→ Coordination Stewardship

Luca supplies material analysis used in the realized output
→ Contribution

Marco performs the final action
→ performer / Actual semantics
```

The same Actor may coincide across roles, but coincidence is contextual rather than ontological.
