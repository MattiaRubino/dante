# 2026-08-16 — Ownership / Possession / Custody integration

Ownership / Possession / Custody v0 resolves the previously deferred Asset-adjacent stewardship boundary.

```text
Coordination Stewardship
= ongoing burden of keeping a bounded coordination context attended

Ownership
= contextual owner relation

Possession
= actual physical holding relation

Custody
= entrusted/safeguarding holding profile where applicable
```

Therefore:

```text
Coordination Stewardship != Ownership
Coordination Stewardship != Possession
Coordination Stewardship != Custody
Coordination Stewardship != generic Asset stewardship

Owner != Steward automatically
Possessor != Steward automatically
Custodian != Steward automatically
Steward != Owner / Possessor / Custodian automatically
```

A custodian may also carry coordination burden, but the two states must be established independently. Safeguarding/return Responsibility inside a Custody profile is not itself Coordination Stewardship.
