# 2026-08-16 — Collective / Membership integration

A true Collective may bear Responsibility where the bounded accountability relation truthfully belongs to the Collective referent.

```text
Collective C
→ Responsibility for bounded commitment X
```

This does not collapse Collective identity into Responsibility and does not manufacture a Collective from several accountable Actors.

```text
Collective != Responsibility
Membership != Responsibility
member != responsible Actor automatically
several Responsible Actors != Collective automatically
```

The same Collective may have members with individual Responsibility relations that differ from the Collective-level Responsibility.

Example:

```text
Collective: household H
Responsibility: H ensures rent is paid

Member Anna: separate Responsibility for initiating transfer
Member Luca: no such individual Responsibility
```

The collective-level relation does not rewrite each member's personal accountability.
