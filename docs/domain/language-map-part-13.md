# 2026-08-16 — Contribution terminology

## Canonical term

### Contribution

Use capitalized **Contribution** for the accepted specific contextual relation family/capability:

> materially meaningful actual input/work attributable to an Actor within a bounded realization, result or output context.

### Contributor

Use **Contributor** only as a contextual Actor role established by an applicable Contribution relation.

```text
Contributor != native entity/root
Contributor != Person subtype
Contributor != Account identity
```

## Do not collapse

```text
Contribution != Participation
Contribution != Responsibility
Contribution != Coordination Stewardship
Contribution != expected performer
Contribution != Actual performer universally
Contribution != Actual
Contribution != Outcome
Contribution != Provenance
Contribution != Evidence
Contribution != Confirmation / Acknowledgement
Contribution != Authority / Visibility
Contribution != ownership
Contribution != credit / recognition / reward
Contribution != causal blame / merit
```

## Ambiguous lower-case language

Generic prose such as:

```text
"this Activity contributes to Goal X"
"factor A contributed to Outcome Y"
```

must not be normalized automatically into the canonical Actor Contribution relation.

For Goal support, use the applicable planning / Criterion-Evaluation semantics. For causal statements, retain bounded domain language until causal semantics are independently validated.

## Preferred questions

```text
Who was involved?
→ Participation

Who was accountable?
→ Responsibility

Who kept the coordination attended?
→ Coordination Stewardship

Who actually performed?
→ performer / Actual semantics

Who materially contributed actual input/work to this bounded realized context?
→ Contribution
```

## Rejected kernel vocabulary

Do not introduce as universal kernel terms from Contribution v0:

```text
ContributionShare

ContributionScore
FairnessScore
MeritScore
Credit
Contributor entity
```
