# 2026-08-16 — Ownership / Possession / Custody terminology

## Ownership

Use capitalized **Ownership** for the accepted specific contextual relation family expressing established ownership of a bounded referent under an applicable ownership context/basis.

Use **Owner** only as a contextual role established by Ownership.

```text
Ownership != Asset identity
Ownership != Possession
Ownership != Custody
Ownership != Responsibility
Ownership != Coordination Stewardship
Ownership != Authority
Ownership != Visibility
```

## Possession

Use capitalized **Possession** for the accepted specific contextual relation family expressing actual physical holding/control of a bounded physical referent.

Use **Possessor** / **Holder** only as contextual roles.

```text
Possession != Ownership
Possession != Location
Possession != Resource Allocation
Possession != Actual use universally
Possession != Custody
```

## Custody

Use **Custody** as bounded vocabulary/profile for entrusted or safeguarding holding where the applicable semantics combine:

```text
Possession / holding
+ safeguarding / return Responsibility
+ Authority / Agreement / policy basis where relevant
```

Do not normalize every possession or responsibility state into Custody.

## Avoid automatic normalization

Do not infer:

```text
"belongs to" → Ownership without context
"has" → Ownership or Possession automatically
"with" → Possession automatically
"responsible for" → Custody automatically
"controls" → Authority / Possession automatically
```

The specific intended semantics must be established from context.

## Rejected kernel vocabulary

Do not introduce from this review:

```text
Owner entity
Holder entity
Custodian entity
PropertyRelationship root
Control root
Property root
OwnershipShare
OwnershipPercentage
Title / Deed universal root
Custody engine
```

Specialist legal/property/IP/financial terms remain outside the kernel until an explicit LifeOS need and owning review justify them.
