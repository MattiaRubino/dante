# 2026-08-16 — Final Whole-Domain language alignment

## Final vocabulary guardrails

```text
Thing
→ do not use as a universal semantic root merely because implementation needs common references

Relation / related_to
→ do not use as semantic-free canonical truth
→ use a specific accepted relation family when meaning is known

technical reference / technical edge
→ implementation mechanism only
→ not ontology authority

Program / Project
→ product-facing profiles/configurations over accepted planning semantics where applicable
→ not automatically independent kernel primitives

Register / Metric
→ historical product/architecture vocabulary
→ do not resurrect universal Register semantics
→ use Observation, Quantity, Criterion/Evaluation and relevant domain semantics as applicable

Capability
→ contextual capability/resource language where applicable
→ not a universal native entity/root merely for provider matching

Document / Note / Image / Recording / Transcript
→ bounded Content Artifact kinds/product vocabulary

File / blob / URL / provider object
→ representation/access/storage semantics, not Content Artifact identity

Location
→ contextual/product spatial vocabulary
→ Place is the scoped native spatial referent where persistent spatial identity matters

Money
→ informal/product language
→ MonetaryAmount is the accepted reusable currency-amount value semantics
```

## Logical-model language rule

Physical names may differ for engineering reasons, but documentation and APIs must not imply semantic equivalence that the Domain Atlas rejects.

Examples:

```text
entity_id technical registry key
!= universal semantic Entity root

relation row
!= universal semantic Relationship

object_type discriminator
!= proof every target shares one domain superclass
```

The final Whole-Domain regression introduces no new semantic root. `REOPEN = 0; UNCLASSIFIED = 0`.
