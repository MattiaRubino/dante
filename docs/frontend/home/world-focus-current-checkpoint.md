## 3. Critical correction: Home AI is not World DANTE

Do not reuse or copy the Home AI surface by analogy.

```text
HOME
cross-life compression/orientation/operation

WORLD FOCUS
scoped expansion, understanding and continuation of one continuity context
```

The underlying DANTE Intelligence capability may be shared, but product presentation, spatial behavior, interaction context and geometry are separate problems.

Any World DANTE UI must be derived from the World product contract and fresh reverse engineering, not from Home component reuse.

## 4. World product definition

Compass:

> **Understand this part of my life and continue from here.**

A World is a user-recognizable continuity context for a significant part of reality.

Core thesis:

> **A World is a shared coordinate system between the user and DANTE for one meaningful continuity context — not a shared source of truth.**

World is not:

```text
Domain owner
folder
life-area taxonomy
dashboard
universal entity container
DB partition
security boundary
AI memory bucket
chat room
mandatory Goal/time-range/KPI surface
```

## 5. World Output Grammar

World Focus is question-driven rather than widget-driven.

Possible output families:

```text

Change
```

A World does not need all of them. Sparse is valid. Missing answers are never filled with fake cards/KPIs/AI prose.

## 6. Dynamic composition rule

The interior is not a fixed page template.

```text
available authorized reality
-> which World questions have useful answers now?
-> ranking/composition
-> restrained current surface
```

Continuity, Next, Change, metrics, charts, etc. are possible answers/renderers, not mandatory permanent slots.

Stable user-owned content remains predictable. Adaptive/ephemeral content may surface bounded current value but may not silently rewrite stable composition.

## 7. DANTE semantic model already closed by WR2

The following product/context semantics are already established and must not be reopened casually:

```text
1. World identity / purpose
2. Stable World relevance definition
3. Current World interaction cursor/session when actually needed
4. Authorized purpose-scoped DANTE context built by Context Builder
```

World context biases relevance; it is not authorization.

DANTE may expand cross-World only when the user's purpose materially requires authorized broader context.

Visible projection and contextual DANTE result must preserve coherent basis/freshness semantics.

A run remains bound to its initiating World/cursor generation even if the user navigates elsewhere.

AI unavailable must not make the World unusable.

## 9. Immediate next gate — World contextual DANTE spatial/presence contract

Before production UI writes, deeply reverse-engineer and stress-test:

- always-visible vs on-demand presence;
- quiet footprint;
- invocation/composer placement;
- long-conversation expansion;
- sidecar/dock/overlay/full-surface alternatives;
- whether and when DANTE consumes persistent layout space;
- how content reflows when DANTE expands;
- interaction with selected module/source/context;
- `explain this` / deictic follow-ups;
- Insight vs conversation relationship;
- Explore vs conversation relationship;
- Proposal/confirmation/action receipt presentation;
- World switch / conversation binding;
- desktop large / laptop / narrow / mobile;
- minimum viable content area;
- focus/keyboard/screen-reader/touch/reduced-motion;
- AI unavailable/degraded state;
- pre-backend shell now vs real streaming/runtime later.

Pressure-test at least Music, Body, Travel, Finance, Study, Relationships, sparse World and dense World.

Compare current mature products for interaction patterns where useful, but do not copy Home or another product's ontology.

No production implementation begins until the user reviews the resulting contract/direction.

## 10. Backend stop line

The current phase may build truthful frontend structure/interaction and deterministic adapters, but not:

- real API endpoints;
- DB/Alembic changes;
- provider integration;
- real model routing/streaming;
- durable Run/Task backend;
- real tool/effect execution;
- fake success pretending those exist.

The final backend vertical must plug into explicit application/interaction boundaries rather than requiring a World UI redesign.
