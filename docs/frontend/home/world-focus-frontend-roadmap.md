## 8. M3-1 — composition configuration foundation

M3-1 fills the client configuration/revision foundation before candidate ranking or manual Customize UI.

Production snapshot:

```text
WorldFocusCompositionConfig
  schemaVersion
  revision
  worldId
  ordered entries[]
```

Entry metadata:

```text
instanceId
kind
visibility: visible | hidden
pinned: boolean
prominenceOverride: lead | null
```

The config does not carry canonical Domain data, AuthZ/disclosure authority, provider truth or executable renderer code.

Schema disposition is explicit:

```text
current
migration-required
unsupported
```

Customization is an isolated transaction:

```text
CURRENT revision N
  ↓
DRAFT(baseRevision=N)
  ↓
pin / unpin / hide / show / move / promote / restore
  ↓
Apply | Cancel
```

Apply creates revision `N+1` only if the base revision is still current. Otherwise it returns `revision-conflict`. Cross-World Apply fails closed; no implicit merge occurs.

### Manual/DANTE invariant

```text
manual UI [M3-3] ----\
                       -> same finite command language -> DRAFT -> REVIEW/APPLY
DANTE proposal [M4] --/
```

Canonical app capabilities that DANTE can propose or accelerate must remain usable through a manual/non-AI path where they are meaningful application functions. DANTE cannot bypass the canonical Apply/revision guard.

M3-1 does not introduce candidate ranking, Customize UI, fake local persistence, new live modules or DANTE runtime work.
