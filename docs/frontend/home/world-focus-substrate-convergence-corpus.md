**Status:** CURRENT WS1–WS5 CONVERGENCE EVIDENCE — ANALYTICAL / PRE-WS6

This document is the durable scenario corpus used by the indivisible **WS1–WS5 World Substrate Convergence Loop**.

It is deliberately UI-agnostic. A scenario describes the user job, relevant reality, useful non-DANTE behavior, DANTE-enhanced behavior, failure pressure and substrate concern. It does **not** prescribe cards, panels, routes, modals, dashboards or final visual hierarchy.

This is analytical falsification evidence. It is **not** executable WS7 proof, backend proof, real-LLM proof or human visual acceptance.

---

## 1. Method

The convergence loop is executed as one macro-block:

```text
scenario
-> deterministic useful path without DANTE
-> DANTE-enhanced path
-> adversarial / edge mutation
-> targeted reverse engineering only for a concrete unresolved gap
-> close / reject / defer the material concern
-> propagate the decision across the corpus
-> repeat
```

No intermediate `WS1 PASS`, `WS2 PASS`, etc. exists.

A World fails the corpus if it requires AI merely to be useful, if a frontend projection replaces canonical semantics, if one special World forces page-per-World architecture, if privacy/authority collapses into visibility, if a provider acknowledgement is shown as canonical completion, or if a visually convenient generic object becomes a new Domain ontology.

```text
cross-World projection reuse

large history / dense candidate output

```

```text
World != canonical Domain owner

```

## 2. Corpus coverage

The primary corpus contains **44 materially different scenarios**.

Each primary scenario is evaluated in two modes:

```text
WITHOUT DANTE
- deterministic useful first-open / continuation path;
- no LLM dependency for basic World usefulness;
- truthful empty/sparse state allowed.

WITH DANTE
- DANTE may explain, compare, discover, simulate or prepare an action;
- DANTE consumes bounded references and authorized purpose-scoped context;
- DANTE does not become source truth, authorization or mandatory navigation.
```

The corpus is intentionally cross-domain. Domain labels are test fixtures, not World types or renderer keys.

### 4.1 First confirmation disposition

The first confirmation wave **did not converge**.

`X04` exposed a new material class:

> A projection/context that was authorized at time T must not remain usable solely because it is mounted, cached or referenced after the authoritative disclosure/authorization basis changes.

This became `CG-32 — Disclosure / authorization revocation invalidation`.

The loop therefore correctly restarted rather than declaring a ceremonial PASS.
