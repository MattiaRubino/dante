Every candidate is attacked with the following sequence:

```text
1. Does current Domain already own the semantic meaning?
2. Is it actually L2/L3/L4/L5/L6/L7/L8 instead of L1?
3. Can it be composed from a smaller accepted L1 primitive + direct Domain projection?
4. Is it merely a query/data shape or renderer pattern?
5. Can it be deleted across materially different scenarios without user-job loss?
6. Can it be merged with another survivor without creating a polymorphic mega-object?
7. Does it remain useful without DANTE?
8. Does unknown-World pressure require it?
```

A candidate is rejected as L1 if a truthful lower/upper owner already exists.

# 3. Protected-main Domain collision checks

WS6 explicitly inspected current accepted Domain semantics rather than relying on old frontend discovery nouns.

## Dependency

Canonical Domain `Dependency` already owns directional contingency on a materially relevant prerequisite state/result/condition.

Therefore no `PrerequisitePrimitive`, `BlockerEdge` or generic workflow dependency is admitted into L1.

## Resource Requirement / Allocation

Canonical semantics already distinguish:

```text
Requirement
candidate set
Allocation
Capacity Claim / reservation where applicable
Actual use
```

No L1 `Requirement`, `ResourceChoice` or `Allocation` duplicate is accepted.

## Session

Canonical Session owns bounded actual execution episodes. Timer/stopwatch/pause/resume are interactions over that source semantics.

No L1 `Execution` primitive is admitted.

## Decision / Proposal / Request

Canonical Domain already distinguishes:

```text
Proposal != Request != Decision != Authority != effect
```

Decision preparation is therefore a composition, not another universal semantic root.

## Criterion / Evaluation

Criterion/Evaluation already owns evaluative rules and assessment semantics, including thresholds/trends/checkpoints where applicable.

No universal L1 `Progress`, `Score`, `GoalProgress`, `ThresholdState` or evaluation primitive is accepted.

## Reconciliation

Canonical Reconciliation already owns the cross-cutting handling of materially competing assertions/states while permitting unresolved conflict.

No L1 `ConflictResolution` primitive is admitted.

## Conditional Policy / Trigger

Trigger is accepted activation vocabulary within Conditional Policy, not a standalone universal entity. No frontend `AutomationRule` or generic `TriggerPrimitive` is admitted.

# 10. Pairwise merge mutants

## M01 Continuity + Attention

Rejected because:

```text
resumable != unresolved
```

A healthy resumable thread may require no attention; a legal deadline can require attention without being a resumable thread.

## M02 Continuity + Comparison

Rejected because checkpoint/resumability semantics and contrast semantics have different ownership and valid absence conditions.

## M03 Continuity + Trajectory

Rejected because creative/qualitative continuity can exist without any ordered metric/series.

## M04 Attention + Comparison

Rejected because an unresolved consequential matter is not merely a difference between alternatives.

## M05 Attention + Trajectory

Rejected because attention may arise from a deadline, request, authority conflict or missing acknowledgement with no trajectory.

## M06 Comparison + Trajectory

Rejected because unordered alternatives/bounded baselines and ordered-series/window/missingness/aggregation are materially different contracts. Merging them creates an analytics mega-object.
