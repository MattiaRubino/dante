# Product Scope

## Core product areas

The initial product definition includes:

- account and personal profile;
- central adaptive calendar;
- goals and deadlines;
- activities, events, routines, and programs;
- daily confirmation and progress tracking;
- schedule recalibration and conflict handling;
- configurable notifications;
- optional modules;
- file import foundations;
- integration foundations;
- replaceable AI gateway.

## Optional module direction

Potential modules include:

- nutrition and meals;
- training and physical activity;
- health measurements;
- learning and language study;
- creative and musical projects;
- travel, outings, events, and photography.

Modules must contribute activities, constraints, data, and progress to the core without coupling the calendar to module-specific implementation details.

## Current exclusions

The following are outside the current scope:

- controlling or launching desktop applications;
- arbitrary shell commands on a user's computer;
- mandatory paid cloud storage;
- Kubernetes deployment at the start;
- a full in-app conversational assistant in the first implementation.

## Open product work

Before implementing the full application, the project still needs:

- a prioritized first-version feature map;
- the essential user flows;
- the first UX prototype for web and mobile;
- precise scheduling and confirmation rules.
