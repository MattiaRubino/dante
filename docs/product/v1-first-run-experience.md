# LifeOS V1 — First-Run Experience

## Principle

The first run should teach the product through light contextual guidance rather than a long tutorial or a confusing empty screen.

LifeOS should help the user complete one meaningful first action quickly while keeping all guidance optional and dismissible.

## Empty-state entry

When the account has no real items yet, the Today view presents:

- a clear prompt such as "What do you want to organise?";
- quick actions for creating an event, activity, routine, goal, program, or import;
- a small set of example prompts;
- optional contextual coach marks or speech-bubble hints pointing to the main controls;
- a visible way to skip or replay the introduction later.

The empty state should remain useful and should not look like a fake populated account.

## Contextual guidance

Guidance should appear in short steps, for example:

1. show where to add an item;
2. explain the difference between a quick item and a program;
3. show where Today and Calendar are located;
4. explain how to edit, move, complete, or delete an item;
5. end after the first successful action.

Each hint must be dismissible. The user should not be forced through every step before using the app.

## First real item preferred

The preferred tutorial asks the user to create a real, simple item, for example:

- an appointment;
- a reminder;
- an activity for later today;
- a recurring routine;
- a first goal.

LifeOS can prefill a harmless example, but the user confirms or replaces it before it becomes real data.

## Optional demonstration item

LifeOS may offer an optional sample item to demonstrate interaction, but it must be clearly marked as a tutorial item.

A tutorial item:

- is stored separately from real planning data;
- does not affect history, statistics, streaks, progress, workload, or AI context;
- is visually labelled as a demo;
- can be edited, moved, completed, reopened, and deleted for practice;
- is removed automatically when the tutorial ends unless the user explicitly converts it into a real item.

The product must never silently mix sample content into the user's actual calendar or analytics.

## Suggested first-run choices

The user can choose among:

- create my first real item;
- show me a quick interactive demo;
- import an existing calendar or plan;
- skip and explore on my own.

## Completion

The first-run experience is considered complete when the user either:

- creates or imports a real item;
- finishes the optional demo;
- explicitly skips the tutorial.

The user can reopen the guided tour from Help or Settings later.
