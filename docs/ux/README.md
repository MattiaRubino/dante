# UX Work

This directory contains approved UX flows, prototype decisions, and open interaction questions.

## Current milestone

- [`today-home-v7.md`](today-home-v7.md) documents the Phase 4 Home/Today prototype, including:
  - adaptive timeline density;
  - overlapping events and activities;
  - expandable sub-items;
  - contextual detail and AI interaction;
  - horizontal expansion by stable global groups;
  - conditional horizontal scrolling;
  - progressive multi-day scrolling.

## Prototype scope

The first coded prototype focuses on:

- application shell and navigation;
- Today view;
- expandable calendar blocks;
- activity creation and detail;
- desktop interaction patterns;
- simulated data and interactions.

Mobile and production implementation remain separate validation steps.
